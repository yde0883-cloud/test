手环质检器 Readme
项目简介
本项目基于 STM32 单片机实现智能手环质检设备，采集两路模拟信号（方波频率信号、直流电压信号），完成电压、频率检测，依据判定标准对手环进行优品 / 良品 / 次品分级，同时统计检测数据，支持按键控制、LED 状态指示、参数修改、数据清零等功能。
硬件说明
输入信号
信号 1：方波信号，模拟手环频率输出，范围：100Hz‑15KHz，峰峰值 3V，直流偏置 1.5V
信号 2：直流电压信号，模拟手环电压输出，范围：0‑3.3V，严禁超过 5V
外设资源
LCD 屏幕：显示两路信号测量值、检测统计数据、检测判定标准
按键：启动 / 停止质检、统计数据一键清零、修改检测标准
LED 指示灯：LED0（优品）、LED1（良品）、LED2（次品），对应等级点亮 1 秒后熄灭
检测判定规则
必须电压、频率同时满足区间条件，才判定为对应等级，任意一项不满足则降级判定。
表格
等级	电压标准	频率标准
优品	2.0V ~ 3.0V	5000Hz ~ 10000Hz
良品	1.0V ~ 2.0V	1000Hz ~ 5000Hz
次品	0‑1.0V 或 ＞3.0V	0‑1000Hz 或 ＞10000Hz
数据显示格式
测量电压：保留 2 位小数
检测标准电压：保留 1 位小数
优品率、良品率、次品率：保留 1 位小数
示例：
电压 3.1V，频率 9000Hz → 次品
电压 1.2V，频率 4000Hz → 良品
电压 2.6V，频率 5800Hz → 优品
功能列表
基础功能
LCD 显示两路信号频率、电压测量结果，测量误差≤5%
按键控制质检程序启动、停止；屏幕展示：优品率、良品率、次品率、总检测数量、产品检测标准
统计数据一键清空：一键重置优品率、良品率、次品率、总检测产品数
进阶功能
检测标准修改：可修改优品 / 良品 / 次品对应的电压、频率判定阈值
LED 分级提示：检测到优品 LED0 亮 1s 熄灭；良品 LED1 亮 1s 熄灭；次品 LED2 亮 1s 熄灭
预留自由发挥扩展接口
性能指标
频率测量范围：100Hz‑15KHz
电压测量范围：0‑3.3V
测量误差：≤5%
